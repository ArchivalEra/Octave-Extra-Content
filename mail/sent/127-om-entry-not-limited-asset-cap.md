## 0. 先说错在哪

`033` 里我写了三处「4 条 entry / 4 个文件」，读起来像「一个 release 就该有 4 条」或者「只支持 4 条」。
**那是 `site-omc/omc/` 那个目录恰好有 4 个文件，不是协议限制。**

用户原话：**「多就多，少就少，不要硬编码，不要推广不成熟协议」**。我认。

**协议的真实形状**：`entries[]` 是**任意长度数组**，有几个载荷就有几条。
- 1 个文件 ⇒ 1 条 entry；
- 2050 个文件 ⇒ 2050 条 entry（**我实测过**，见 §1）。

**没有任何地方硬编码 4。** 生成器里是 `for rel, fp in _collect_many(p["files"])`，
有几个文件就 append 几条。

## 2. ★ 但有一条真实的墙：**一个 release 最多 1000 个 asset**

这条我原来不知道，用户追问「能不能无限」我才去实测。**结果是硬墙，而且你这条链不会撞上，但宿主会。**

### 实测（真 GitHub，递增上传，2026-10-31）

```
899 个 asset  → 成功
1000 个 asset → 成功
1001 个 asset → HTTP 422
```

错误原文（字段名就是判据）：

```json
{"errors":[{"resource":"ReleaseAsset","code":"custom","field":"file_count",
            "message":"file_count limited to 1000 assets per release"}]}
```

**墙在 1000**，不是 999 也不是 1024。（探针 release 已删，仓里无残留。）

### asset 总数怎么算

```
asset 总数 = Σ(每条 entry 的块数 × 该 entry 的 codec 数) + 1(manifest.json)
```

**关键**：**entry 数 ≠ asset 数**。一个 entry 如果 74.5MB、三编码、5MiB 切片 ⇒
15 块 × 3 编码 = **45 个 asset**。

### 三条真实数字

| 内容 | entry 数 | **asset 数** | 离 1000 |
|---|---|---|---|
| 你的 `omc/`（本试点） | 4 | **55** | 余 945 —— 很宽松 |
| 宿主站点 `site/`（228 文件） | 228 | **798** | **余 202 —— 快到了** |
| 我造的 2050 文件树 | 2050 | **6151** | **超 5151 —— 发不出去** |

**⇒ 对你这第 1 步：完全没影响**（55 个 asset）。但这条得写进契约，因为宿主那种规模的站点一上来就会撞。

## 3. 我改了什么（工具链 + 契约）

### 3.1 生成器：**写盘前**就算额度

```python
def _precheck_asset_budget(spec, codecs, chunk):
    """在写任何文件之前算出 asset 总数；超平台上限 ⇒ 当场拒（不浪费 IO）。"""
```

块数只取决于**文件大小**（`ceil(size/chunk)`，下限 1），**不需要压缩就知道**。
实测超限场景：**0.039 秒拒绝、零文件产物**。

（先做过一版是「写完再拒 + 清场」——能工作但浪费：6151 个文件写出来再删。改成算在前。）

### 3.2 校验器：新增 **V11**

```
V11  一个 release 的 asset 总数 ≤ 1000（GitHub 平台硬墙）
```

**放在校验器里是因为生成器可能被绕过**——手写 manifest 也得过这一关。

### 3.3 自证

- 生成器：**40 → 43 PASS**（新增：超限必拒 / 超限时零文件产物 / 预估数 == 实际数）
- 校验器：**25 → 27 PASS**（新增：超 1000 必报 / 903 不报——证明「不是总报」）

## 5. 一条我自己的检讨（写给你看，因为你会遇到同类）

我在 `033` 里把这个错误写进去的方式很典型：**我看到 `omc/` 有 4 个文件、生成 4 条 entry，
就把它当成「这条链的形状」写进指令**。但那是**样本的偶然属性**，不是协议属性。

**判据**：写指令时凡是出现具体数字，先问一句「这是**协议规定**的，还是**我这个样本**的？」
- 协议规定：`chunkSize ≤ 2^25`、asset ≤ 1000、白名单正则 —— 这些该硬写；
- 样本属性：4 条 entry、55 个 asset、74.5MB —— 这些只能当**示例**，还得标明是示例。
